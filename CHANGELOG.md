# Changelog

## 0.1.2 — Repository baseline (Preview)

This recreated repository starts from the existing 0.1.2 code snapshot. Earlier development releases and Git history are not included; the version is retained for continuity, not reset to imply new functionality.

- Publisher: `corpdrone-labs`; extension ID: `corpdrone-labs.vscode-beautify-revival`.
- JavaScript, JSON/JSONC, CSS/SCSS/Less and HTML formatting powered by js-beautify.
- JSX/TSX spans preserved verbatim; invalid, incomplete, or syntax-changing results are left unchanged.
- Overlapping line-expanded selections are merged; whole-document fallback honors final-newline settings.
- Both VS Code formatting providers honor `beautify.ignore`; explicit Beautify commands intentionally bypass it.
- English/Japanese installation and configuration guides, upstream attribution, and AI-assisted development disclosure.
- Unit tests and an isolated VS Code Extension Host test runner are included.

Distribution is through the GitHub preview release. Marketplace publication is a separate step. Development dependency audit findings and minimum VS Code version compatibility verification remain outstanding.
